# Security Policy

## Supported Versions

AURA Framework security updates are actively provided for the following versions:

| Version | Supported |
| :--- | :--- |
| 1.x.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability within AURA Framework, please report it responsibly by emailing security@auraframework.org or opening a private security advisory on GitHub.

Please include:
- Description of the vulnerability and potential impact.
- Steps or proof-of-concept to reproduce the issue.

We appreciate your effort in keeping AURA Framework secure for everyone.
